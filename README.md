# Cosmic Canvas Creation

crie um site para mim, sobre o espaço, personalize o design, ajustando o layout, cores, tipografia e identidade visual, além de adicionar conteúdo relevante, como seções institucionais e imagens. Para tornar o site mais dinâmico, implementem pelo menos uma funcionalidade interativa, como um quiz, simulador, calculadora ou um jogo simples. Testem todas as funcionalidades para garantir que o site esteja responsivo e funcional. Por fim, documentam todo o processo, incluindo a justificativa da escolha da ferramenta, as personalizações realizadas e a explicação da funcionalidade interativa adicionada. Compilem as informações em um documento organizado e submetam o arquivo de relatório.
